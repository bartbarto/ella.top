# ella.top

Personal portfolio site built with Vue 3 and Vite.

## Setup

```bash
yarn
```

## Development

```bash
yarn dev
```

Opens a local Vite server (usually at `http://localhost:5173`).

## Build

```bash
yarn build
```

Outputs a production build to `dist/`. Preview it with:

```bash
yarn preview
```

## Deploy (GitHub Pages)

Pushes to `main` trigger `.github/workflows/deploy.yml`, which builds with Yarn and publishes `dist/` to GitHub Pages.
